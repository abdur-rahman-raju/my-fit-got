# FitLog

FitLog is a workout library and planning application built with Next.js. Users can explore workouts, view workout details, add exercises to their daily plan, save workouts, and track completed exercises.

## Features

* Browse workouts from an API
* View detailed workout information
* Add workouts to Today's Plan
* Save workouts for later
* Mark workouts as completed
* Remove workouts from Plan or Saved
* Sort workouts by duration, calories, and rating
* Toast notifications for user actions
* LocalStorage for saving Plan and Saved data
* Responsive design

## Technologies

* Next.js
* TypeScript
* React
* Tailwind CSS
* React Toastify
* LocalStorage
* REST API
